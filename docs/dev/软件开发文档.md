# DNC参数计算系统 - 软件开发文档

## 1. 系统概述

DNC参数计算系统是一个基于Python的参数化计算工具，用于处理产品数据、计算几何参数并生成宏变量输出。系统支持从CSV文件导入数据，匹配产品型号，并根据预定义规则计算输出宏变量。

## 4. 核心功能模块

### 4.1 型号匹配功能

系统实现了一种从后往前逐字符删除的型号匹配算法：
- 从输入型号的末尾开始逐字符删除
- 与type_define.csv中的型号进行匹配
- 支持连字符和下划线格式转换的匹配

### 4.2 数据发送功能

系统根据cntrl.csv中的SENDFLG标志输出宏变量到macro.txt文件：
- 只输出SENDFLG为1的宏变量
- 跳过空值宏变量，不输出默认值
- 支持关系表达式计算

### 4.3 程序控制功能

支持多个程序（prg1, prg2, prg3）：
- 根据type_prg.csv确定程序显示顺序
- 动态加载程序特定的控件
- 程序间切换功能

### 4.4 接口文件监控功能

- 监控interface/input.txt文件变更
- 自动读取文件内容并模拟输入
- 支持自动发送数据（仅接口文件输入）

### 4.5 控件类型支持

系统支持多种控件类型：
- `load`: 加载类型控件
- `input`: 输入类型控件（浅蓝色背景）
- `measure`: 测量类型控件
- `select`: 选择类型控件
- `relation`: 关系类型控件
- `switch`: 开关类型控件
- `correct`: 修正类型控件

## 5. 数据流处理

### 5.1 型号处理流程

1. 用户输入型号（通过扫码枪或接口文件）
2. 系统使用`_find_matching_model`方法进行匹配
3. 匹配成功后调用`_process_model`方法
4. 根据匹配结果加载相应程序控件
5. 显示产品数据和参数

### 5.2 数据发送流程

1. 用户点击"发送数据"按钮或接口文件自动触发
2. 系统读取cntrl.csv中的SENDFLG标志
3. 收集所有SENDFLG为1的宏变量
4. 跳过空值宏变量
5. 将有效宏变量写入output/macro.txt文件

### 5.3 界面更新流程

1. 数据加载完成后更新产品目录标签页
2. 型号匹配后更新型号显示
3. 参数修改后实时更新界面
4. 操作完成后更新状态栏
